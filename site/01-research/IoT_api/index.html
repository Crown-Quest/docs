Interface & API Unity vers Haptic / IOT¶

Principe¶

Le système repose sur un principe Audio-to-Haptic.
Le son est analysé puis transformé en vibrations via des fonctions de mapping.

Chaîne de fonctionnement¶

Son → Fonctions de mapping → Vibrations

Référence Audio-to-Haptic¶

Tutoriel Unity :
https://learn.unity.com/tutorial/2-1-audio-and-haptics-2

Développement bHaptics¶

Le développement s’appuie sur le SDK bHaptics.
Documentation et ressources développeur :

  • https://www.bhaptics.com/fr/support/developers/?type=sdk
  • https://docs.bhaptics.com/

Communication¶

La communication avec les dispositifs se fait via Bluetooth.

Technologie¶

La solution est conçue pour être facilement développable à partir de zéro.
